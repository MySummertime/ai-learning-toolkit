# 探索手册界面规范

Vocabulary Atlas 使用「植物标本册」视觉语言：暖纸白页面、墨棕文字、深森林绿操作色，配以浅叶绿选择态、少量陶土红收藏标记。页面背景以中性纸色为主，绿只用于主要操作、植物关系、成功状态和导航强调，避免大面积同色铺满。折页插画只出现在加载和空地图等无学习内容的位置；真实图谱的节点、关系线和词义区不叠装饰。页面只强调当前内容和一个主要行动。

## 权威来源

- `config.yaml` 管理所有可配置颜色与图谱关系色，前端从启动配置注入 CSS 变量；首次加载前的 CSS 备用色须与配置同步；修改配置后重启服务。应用内不提供全局配置编辑界面。
- `field-guide.css` 管理字号、间距、圆角、阴影、动效与响应式布局。组件应使用其中的尺度，避免新增零散数值。
- `styles.css` 保留原有布局与功能样式；新视觉规则集中在后加载的 `field-guide.css`。调整既有页面时，优先更新后一文件并移除被明确取代的旧规则。

## 页面层级

| 页面 | 首要内容 | 首要行动 |
| --- | --- | --- |
| 词汇地图 | 当前词、可见关系与搜索 | 搜索或选择单词 |
| 单词条目 | 词头、发音、核心释义 | 阅读并收藏 |
| 背单词 | 当日单词与练习进度 | 继续当前练习 |
| 词表 | 词表及词数 | 新建或打开词表 |
| 词典 | 搜索结果 | 打开词条 |
| 日历 | 日期与对应计划 | 查看当日学习内容 |
| 收藏夹 | 收藏的词条 | 打开词条 |

## 配色与形状

- 页面背景使用暖纸白，卡片使用更亮的纸白，抬高表面用浅暖灰。深森林绿负责主操作、焦点和成功状态，浅叶绿负责局部选中，陶土红只标记收藏和少量提醒。
- 图谱使用无网格的浅雾绿底色。同族和同义用深森林绿、近义用赭褐色、反义用陶土红、拼写相似用灰紫色；每种关系同时用颜色与线型区分，待核验连线使用虚线。
- 节点只显示完整词头，圆半径随词长增加；释义、词性和词族说明不压进节点。关系以轻弧线连接节点，颜色在图谱底色上保持清楚。
- 主按钮为深蓝绿色实心胶囊，次按钮为纸白底的轻量描边胶囊；背词首页将两者放进同一组底托，并用箭头与日历图标区分操作。危险操作始终使用独立错误色。卡片和弹窗共用圆角、边框与阴影尺度。


## 交互与检查

- 直接操作的过渡使用约 160 毫秒，图谱聚焦约 240 毫秒；拖拽保持即时反馈。遵循 `prefers-reduced-motion`。
- 窄屏词条使用「词汇地图／单词条目」切换；桌面保留分屏和独立显示。隐藏的面板不应阻断可见面板的操作。
- 正文与关键按钮以至少 4.5:1 的文字对比度为目标，键盘焦点必须明显。每次修改页面后检查桌面、平板和窄屏，以及加载、空白、错误和高密度图谱状态。

## 图谱浏览流程

- 在“词典”查词，点击结果后直接显示中心词及其关联词；点击节点可查看单词笔记。
- 在“词表”选择词表后，图谱按词表顺序分组，默认每组 20 词，并显示这一组的直接关联词。上一组、下一组和分组下拉框切换组；搜索覆盖整张词表。
- 默认选择同族词，其余关系通过单选切换。“更多关联词”只在中心词视图显示，展开该词的直接关系。
- `applications/vocabulary-atlas/config.yaml` 的 `graph.browsing` 配置组大小、画布节点上限、默认及展开后的关联词数量。默认节点上限 80，关联词数量为 12 / 30；修改配置后重启服务。
- 节点颜色由 `graph.nodes` 配置。收藏与界面状态分别保存在 `favorites-state.json` 和 `ui-state.json`，词表保存在 `projects/<projectId>/project.json`。
